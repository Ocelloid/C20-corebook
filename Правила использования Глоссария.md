# Правила использования Глоссария при переводе разделов книги Changeling: The Dreaming

## Назначение

Данный документ содержит инструкции для использования файла `Глоссарий.md` при переводе разделов книги Changeling: The Dreaming 20th Anniversary Edition с английского языка на русский.

## Промпт для ИИ-переводчика

При переводе разделов книги используйте следующий промпт:

---

**ИНСТРУКЦИЯ ПО ПЕРЕВОДУ С ИСПОЛЬЗОВАНИЕМ ГЛОССАРИЯ**

Вы переводите раздел книги Changeling: The Dreaming 20th Anniversary Edition. При переводе ОБЯЗАТЕЛЬНО используйте прилагаемый глоссарий для обеспечения терминологической согласованности.

### СТРУКТУРА ГЛОССАРИЯ

Глоссарий организован по следующим категориям:

- **Основные концепции и мироустройство** - ключевые термины сеттинга
- **Наследия (Legacies)** - возрастные категории фей
- **Магическая система** - Искусства (Arts) и Сферы (Realms)
- **Игровые механики** - правила и системы
- **География и королевства** - места и локации
- **Киты (Kith)** - расы фей
- **Благородные дома** - аристократические кланы
- **Враги и антагонисты** - противники
- **Различные роды фей** - Таллайн, Нунехи, Менехуне, Хсьен, Инанимэ
- **Титулы и звания** - социальная иерархия
- **Предметы и артефакты** - магические вещи

### ПРАВИЛА ИСПОЛЬЗОВАНИЯ ГЛОССАРИЯ

1. **ОБЯЗАТЕЛЬНАЯ ПРОВЕРКА**: Перед переводом любого термина проверьте его наличие в глоссарии.

2. **ТОЧНОЕ СООТВЕТСТВИЕ**: Используйте ТОЧНО тот перевод, который указан в глоссарии. Не изменяйте его даже если кажется, что можно перевести по-другому.

3. **КОНТЕКСТНАЯ ПРОВЕРКА**: В глоссарии для каждого термина указаны контексты использования с указанием раздела и страницы. Проверяйте соответствие контекста.

4. **ПОСЛЕДОВАТЕЛЬНОСТЬ**: Если термин встречается в тексте несколько раз, используйте одинаковый перевод во всех случаях.

5. **КРИТИЧЕСКОЕ ПРАВИЛО - ТЕРМИНОЛОГИЯ "ФЕЯ/ФЕЙСКИЙ"**:

   - ✅ **ВСЕГДА** используйте "фея" вместо "фейри"
   - ✅ **ВСЕГДА** используйте "фейский/фейская/фейское" вместо "фейрийский/фэйрийский"
   - ❌ **НИКОГДА** не используйте "фейри", "фейрийский", "фэйрийский" и подобные
   - Это правило применяется ко ВСЕМ производным от "fae/faerie/fairy"

6. **НОВЫЕ ТЕРМИНЫ**: Если встречается термин, отсутствующий в глоссарии:

   - Переведите его согласно общим принципам перевода
   - Отметьте этот термин в комментарии для добавления в глоссарий
   - Используйте консистентный перевод в рамках текущего раздела

7. **ИМЕНА СОБСТВЕННЫЕ**:

   - Имена персонажей, мест, артефактов переводите согласно глоссарию
   - Если имя отсутствует в глоссарии, используйте транслитерацию

8. **ГРАММАТИЧЕСКИЕ ФОРМЫ**: Адаптируйте переводы из глоссария под грамматические требования русского языка (падежи, числа и т.д.), сохраняя основу термина.

### ПРИМЕРЫ КЛЮЧЕВЫХ ТЕРМИНОВ

- **Changeling** → Подменыш
- **Dreaming** → Грезы
- **Glamour** → Очарование
- **Banality** → Банальность
- **Kithain** → Китайн
- **Seelie Court** → Двор Благих
- **Unseelie Court** → Двор Неблагих
- **Childling** → Дитя
- **Wilder** → Юноша
- **Grump** → Старец

### ПРИМЕРЫ ПРАВИЛЬНОЙ ТЕРМИНОЛОГИИ "ФЕЯ/ФЕЙСКИЙ"

- **fae nature** → **фейская природа** (НЕ "фейрийская")
- **faerie sanctuary** → **фейское убежище** (НЕ "фейрийское")
- **fairy freehold** → **фейский фригольд** (НЕ "фейрийский")
- **fae mien** → **фейское обличье** (НЕ "фейрийское")
- **faerie magic** → **фейская магия** (НЕ "фейрийская")
- **fairy realm** → **фейское королевство** (НЕ "фейрийское")

### КАЧЕСТВО ПЕРЕВОДА

Обеспечьте:

- **Терминологическую согласованность** с глоссарием
- **Естественность** русского языка
- **Сохранение стиля** оригинала
- **Понятность** для русскоязычного читателя
- **Соответствие жанру** фэнтези/хоррор RPG

### ФИНАЛЬНАЯ ПРОВЕРКА

После перевода:

1. Проверьте все термины на соответствие глоссарию
2. Убедитесь в консистентности переводов внутри текста
3. Отметьте новые термины для добавления в глоссарий

## Дополнительные рекомендации

### Для переводчиков-людей:

- Всегда имейте открытым файл глоссария при переводе
- Используйте функцию поиска (Ctrl+F) для быстрого нахождения терминов
- Ведите заметки о новых терминах для последующего добавления в глоссарий

### Для технических специалистов:

- Рассмотрите возможность автоматизации проверки терминов
- Создайте скрипты для валидации соответствия переводов глоссарию
- Интегрируйте проверку глоссария в процесс контроля качества

### Обновление глоссария:

- Регулярно дополняйте глоссарий новыми терминами из переведенных разделов
- Следуйте правилам, изложенным в файле `Правила пополнения Глоссария.md`
- Поддерживайте актуальность контекстных ссылок

## Контроль качества

Перед публикацией перевода раздела:

1. Проведите финальную проверку всех терминов по глоссарию
2. Убедитесь в отсутствии терминологических противоречий
3. Проверьте соответствие стилистики оригинала
4. Обновите глоссарий новыми найденными терминами
