# Changeling: The Dreaming 20th Anniversary Edition - Проект перевода

Проект по переводу настольной ролевой игры **Changeling: The Dreaming 20th Anniversary Edition** с английского языка на русский.

## 📖 О проекте

Данный проект представляет собой комплексную систему для перевода книги объёмом 482 страницы с использованием автоматизированных инструментов и строгой терминологической базы.

### 🎯 Цели проекта

- Создание качественного русского перевода книги Changeling: The Dreaming 20th Anniversary Edition
- Обеспечение терминологической согласованности на протяжении всего текста
- Разработка воспроизводимого процесса перевода больших RPG-книг
- Создание инструментов для автоматизации работы переводчиков

## 🚀 Процесс перевода

### TLDR:

- Разбиваем PDF на отдельные страницы
- Из каждой страницы извлекаем текст и картинки
- Текст объединяем в разделы
- Из разделов извлекаем термины для глоссария
- Переводим термины в ручную и форматируем в csv
- Формируем правила для языковой модели по переводу с использованием глоссария
- Переводим с помощью claude-4-sonnet в Курсоре по паре страниц за раз с указанными правилами

Получается примерно 40 страниц в час.

### Этап 1: Подготовка исходных материалов

#### 1.1 Анализ PDF файла

```bash
# Установка зависимостей
pip install -r scripts/requirements.txt

# Анализ исходного файла
python scripts/check_pdf.py source.pdf
```

**Результат:** Анализ показал, что файл содержит 482 страницы, ~642 изображения, готов к обработке без проблем.

#### 1.2 Разделение PDF на страницы

```bash
# Полная обработка PDF (разделение + извлечение текста и изображений)
python scripts/process_pdf_complete.py source.pdf

# Или поэтапно:
python scripts/split_pdf_pages.py source.pdf    # Разделение на страницы
python scripts/extract_text.py                  # Извлечение текста
python scripts/extract_images.py                # Извлечение изображений
```

**Результат:**

- 482 PDF-страницы в папке `pages/`
- 482 Markdown-файла с текстом
- ~642 изображения в исходном качестве

#### 1.3 Организация по главам

```bash
# Копирование страниц в структуру глав
python scripts/copy_pages.py

# Объединение страниц каждой главы в единый файл
python scripts/merge_sections.py

# Очистка дублирующих заголовков
python scripts/clean_section_files.py
```

**Результат:** 18 файлов разделов готовых к переводу в папке `chapters/`.

### Этап 2: Создание терминологической базы

#### 2.1 Составление глоссария

Каждый из 18 файлов был проанализирован с помощью claude-4-sonnet на наличие слов, не содержащихся в обычном английском языке, и игровых терминов. **`Правила пополнения Глоссария.md`** содержат использованный промпт. После этого был выбран подходящий перевод для каждого термина.

Создан комплексный глоссарий `Глоссарий.md` содержащий:

- **700+ терминов** игровой системы Changeling: The Dreaming
- **71 тематическая категория** (киты, искусства, королевства, дома, враги и т.д.)
- **Контекстные ссылки** с указанием раздела и страницы использования
- **Точные русские переводы** для каждого термина

Дальше глоссарий был переведён в формат csv для удобства использования языковой моделью.
**`Правила использования Глоссария.md`** - содержат промпт для языковой модели по использованию глоссария.
**`Правила перевода.md`** - практические рекомендации по переводу.
На основе этих двух файлов были сформированы правила в папке .cursor/rules для интеграции в IDE Cursor.

#### 2.2 Инструменты работы с глоссарием

```bash
# Универсальный инструмент (рекомендуется)
python scripts/glossary_tools.py fix    # Автоматическое исправление всех проблем

# Или отдельные операции:
python scripts/glossary_tools.py analyze    # Анализ структуры
python scripts/glossary_tools.py validate   # Проверка корректности
python scripts/glossary_tools.py merge      # Объединение дубликатов
```

### Этап 3: Перевод разделов

Перевод совершается с использованием модели claude-4-sonnet в IDE Cursor.

Пример типичного промпта:

```
Продолжи переводить раздел 08 со следующей парой страниц.
Не трать время (и токены) на суммаризацию и содержание страниц в чате.
Внимательно смотри в глоссарий!
Проверяй в нём каждый термин, который не характерен для обычного английского языка, и в принципе каждый игровой термин.
Тебе обязательно нужно проверять глоссарий, это необходимо. Добавляй новый текст в конце файла.
```

В правила в .cursor/rules включена более подробная методология перевода.

### Этап 4: Контроль качества

Есть проблемки, модель не всегда понимает, что переводит, и иногда использует не очень аккуратные формулировки и англицизмы, типа "Долго после этого, дверь открылась" вместо "спустя долгое время, дверь открылась".
Так что вычитывать и редактировать всё равно надо, но это лучше, чем ничего.
И можно будет потом результат так же сформировать в хранилище в обсидиане и по сути использовать как вики.

...уж всяко лучше чем "драконьи койки" лмао
