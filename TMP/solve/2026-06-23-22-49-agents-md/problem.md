# Проблема — agents-md

Создано: 2026-06-23-22-49

## Описание

Проект C20-corebook — перевод Changeling: The Dreaming 20th Anniversary Edition (482 страницы) с английского на русский. Новые AI-агенты, открывая репозиторий впервые, не имеют никакого контекста о структуре, процессах и соглашениях проекта, что приводит к ошибкам (неверные термины, нарушение пайплайна, работа с не теми файлами).

## Желаемый результат

Файл `AGENTS.md` в корне репозитория — быстрый онбординг для нового AI-агента:
- Формат: Markdown, читаемый в Cursor и любом просмотрщике
- Объём: достаточный для полного понимания контекста, но без воды
- Аудитория: новый агент, открывающий репозиторий впервые

## Содержание файла

1. Что за проект (CtD, 482 стр., RPG-перевод)
2. Структура репозитория и пайплайн данных
3. Глоссарий и правила его использования
4. Рабочий процесс перевода (key rules, распространённые ошибки)
5. Quartz-сайт (ctd-quartz/, ctd.ocelloid.com, команды сборки)
6. Скрипты Python
7. Что нельзя трогать
8. Текущий статус перевода

## Ограничения

- Язык файла: английский (AGENTS.md — стандарт для AI-агентов)
- Не пересказывать правила дословно — только ключевые указатели и критические предупреждения
- Стиль: инструктивный, конкретный, без лишних вступлений
