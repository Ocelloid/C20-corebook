В файле source.pdf находится книга длиной в 482 страницы. В этом проекте мы займёмся переводом этой книги на русский язык. Для этого нужно:

- разделить книгу на страницы, сохраняя возможность выделять текст и изображения, и для каждой страницы создать папку в которой будет лежать эта страница в пдф
- для каждой страницы выделить текст и сохранить как файл в маркдаун в той же папке
- для каждой страницы извлечь изображения и поместить в ту же папку

В первую очередь нам нужно будет написать скрипты, которые смогут выполнить каждый из этих шагов. Начнём с первого шага - разделения файла на страницы в отдельных папках. #### **1. Технические проблемы:**

- **Зависимости**: Требуется установка PyMuPDF (`pip install pymupdf`)
- **Размер файлов**: 482 страницы × ~3 файла на страницу = ~1400+ файлов
- **Дисковое пространство**: Может потребоваться значительное место

#### **2. Проблемы с содержимым PDF:**

- **Защищенные PDF**: Файл может иметь пароль или ограничения
- **Сканированные страницы**: Текст в изображениях не извлечется обычными методами

- **Кодировка**: ~~Проблемы с кириллицей в тексте~~ (книга на английском)

- **Порядок чтения**: PyMuPDF может извлекать текст не в том порядке
- **Форматирование**: Потеря исходного форматирования в markdown
- **Изображения**: Могут быть встроены как векторные объекты
- **Метаданные**: Потеря информации о заголовках, структуре
