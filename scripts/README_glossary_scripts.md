# Скрипты для работы с глоссарием

Этот набор скриптов предназначен для автоматизации работы с файлом `Глоссарий.md`.

## Описание скриптов

### 0. `glossary_tools.py` ⭐

**Универсальный инструмент для работы с глоссарием**

Удобная обертка для всех остальных скриптов с простым интерфейсом командной строки.

**Возможности:**

- Единая точка входа для всех операций
- Команда `fix` для автоматического исправления всех проблем
- Подробная справка по использованию
- Цветной вывод и прогресс-индикаторы

**Использование:**

```bash
# Показать справку
python scripts/glossary_tools.py help

# Анализ структуры
python scripts/glossary_tools.py analyze

# Валидация
python scripts/glossary_tools.py validate

# Объединение дубликатов
python scripts/glossary_tools.py merge

# Полный цикл исправлений (рекомендуется)
python scripts/glossary_tools.py fix
```

### 1. `merge_glossary_duplicates.py`

**Основной скрипт для объединения дубликатов**

Автоматически находит и объединяет дублированные записи в глоссарии, сохраняя всю информацию из всех дубликатов.

**Возможности:**

- Поиск дублированных терминов (записей с одинаковыми заголовками `### Term`)
- Объединение контекстов из всех дубликатов
- Выбор наилучшего перевода (самый длинный/полный)
- Создание резервной копии перед изменениями
- Подробный отчет о проделанной работе

**Использование:**

```bash
# Обработка файла Глоссарий.md в текущей директории
python scripts/merge_glossary_duplicates.py

# Обработка конкретного файла
python scripts/merge_glossary_duplicates.py path/to/Глоссарий.md
```

### 2. `analyze_glossary.py`

**Скрипт для анализа структуры глоссария**

Предоставляет подробную статистику о содержимом и структуре глоссария.

**Возможности:**

- Общая статистика (количество строк, символов, размер)
- Анализ структуры заголовков
- Поиск дубликатов
- Анализ переводов и записей без переводов
- Статистика контекстных ссылок
- Распределение по разделам

**Использование:**

```bash
# Анализ файла Глоссарий.md
python scripts/analyze_glossary.py

# Анализ конкретного файла
python scripts/analyze_glossary.py path/to/Глоссарий.md
```

**Пример вывода:**

```
=== АНАЛИЗ СТРУКТУРЫ ГЛОССАРИЯ ===

📄 Общая информация:
   Строк: 6,818
   Символов: 245,832
   Размер: 240.1 KB

📋 Структура заголовков:
   Заголовки 1-го уровня (# ): 0
   Заголовки 2-го уровня (##): 23
   Заголовки 3-го уровня (###): 769 (термины)

🔍 Анализ дубликатов:
   Всего терминов: 769
   Уникальных терминов: 756
   Дублированных терминов: 13
```

### 3. `validate_glossary.py`

**Скрипт для валидации структуры глоссария**

Проверяет корректность форматирования и структуры глоссария.

**Проверки:**

- Правильность структуры заголовков
- Наличие обязательных секций (Контекст, Перевод)
- Корректность форматирования контекстных ссылок
- Поиск дубликатов
- Проверка пустых переводов
- Валидация форматирования

**Использование:**

```bash
# Валидация файла Глоссарий.md
python scripts/validate_glossary.py

# Валидация конкретного файла
python scripts/validate_glossary.py path/to/Глоссарий.md
```

**Коды возврата:**

- `0` - валидация прошла успешно
- `1` - найдены ошибки

## Рекомендуемый порядок использования

### 🚀 Быстрый старт (рекомендуется)

Используйте универсальный инструмент для автоматического исправления всех проблем:

```bash
python scripts/glossary_tools.py fix
```

### 📋 Пошаговый процесс (для детального контроля)

1. **Анализ** - сначала проанализируйте структуру:

   ```bash
   python scripts/glossary_tools.py analyze
   # или
   python scripts/analyze_glossary.py
   ```

2. **Валидация** - проверьте корректность:

   ```bash
   python scripts/glossary_tools.py validate
   # или
   python scripts/validate_glossary.py
   ```

3. **Объединение дубликатов** - если найдены дубликаты:

   ```bash
   python scripts/glossary_tools.py merge
   # или
   python scripts/merge_glossary_duplicates.py
   ```

4. **Повторная валидация** - убедитесь, что все исправлено:
   ```bash
   python scripts/glossary_tools.py validate
   ```

## Структура записи в глоссарии

Скрипты ожидают следующую структуру записей:

```markdown
### Термин

Контекст:

- Раздел `название_раздела` (стр. X): описание контекста
- Раздел `другой_раздел` (лексикон): другое описание

Перевод: Перевод термина
```

## Безопасность

- Скрипт `merge_glossary_duplicates.py` автоматически создает резервную копию файла с расширением `.backup`
- Все изменения логируются в консоль
- При обнаружении критических ошибок скрипт останавливается

## Требования

- Python 3.6+
- Стандартные библиотеки Python (re, sys, pathlib, collections)
- Кодировка файлов: UTF-8

## Примеры использования

### Быстрая проверка на дубликаты

```bash
python scripts/analyze_glossary.py | grep -A 10 "Анализ дубликатов"
```

### Интеграция в CI/CD

```bash
# Валидация в пайплайне
python scripts/validate_glossary.py
if [ $? -ne 0 ]; then
    echo "Глоссарий содержит ошибки!"
    exit 1
fi
```

### Пакетная обработка

```bash
# Обработка всех глоссариев в директории
for file in */Глоссарий.md; do
    echo "Обрабатываем $file"
    python scripts/merge_glossary_duplicates.py "$file"
done
```

## Устранение неполадок

### Ошибка кодировки

Убедитесь, что файл сохранен в кодировке UTF-8.

### Неправильное форматирование

Скрипт валидации покажет конкретные строки с ошибками форматирования.

### Потеря данных

Всегда проверяйте резервную копию (файл с расширением `.backup`) перед удалением.
