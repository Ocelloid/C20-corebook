# Анализатор шрифтов в PDF файлах

Скрипт `extract_fonts.py` предназначен для извлечения и анализа информации о шрифтах из всех PDF файлов в проекте.

## Возможности

- **Рекурсивный поиск**: Находит все PDF файлы в папке chapters и её подпапках
- **Детальный анализ**: Извлекает название, тип, кодировку шрифтов
- **Статистика**: Подсчитывает использование шрифтов по файлам и страницам
- **Отчет в Markdown**: Создает подробный отчет в файле `fonts.md`
- **Безопасность**: Правильное управление ресурсами PyMuPDF

## Использование

### Анализ всех PDF файлов в проекте

```bash
python scripts/extract_fonts.py
```

### Анализ конкретной папки

```bash
python scripts/extract_fonts.py chapters/05_chapter_one_a_world_of_darkness
```

### Анализ с указанием выходного файла

```bash
python scripts/extract_fonts.py chapters/00_credits_and_dedication
```

## Структура отчета

Создаваемый файл `fonts.md` содержит:

1. **Общую статистику**

   - Количество обработанных файлов
   - Количество найденных уникальных шрифтов
   - Статистику по ошибкам

2. **Топ шрифтов по использованию**

   - Таблица с самыми используемыми шрифтами
   - Количество файлов, ссылок, страниц

3. **Полный список шрифтов**

   - Детальная информация по каждому шрифту
   - Список файлов, где используется шрифт
   - Типы и кодировки

4. **Статистику по файлам**

   - Информация о шрифтах в каждом PDF файле

5. **Анализ типов шрифтов**
   - Распределение по типам (CFF, TTF, CID)
   - Распределение по кодировкам

## Пример результатов

Для проекта Changeling: The Dreaming было найдено:

- **482 PDF файла** обработано
- **27 уникальных шрифтов** найдено
- **470 файлов** содержат шрифты
- **12 файлов** без шрифтов (обычно изображения)

### Топ-5 шрифтов:

1. **GoudyStd** - 459 файлов (основной текст)
2. **Kells** - 431 файл (заголовки)
3. **Kells-SC700** - 409 файлов (малые заглавные)
4. **GoudyStd-Bold** - 315 файлов (жирный текст)
5. **GoudyStd-Italic** - 202 файла (курсив)

### Типы шрифтов:

- **CFF** (Compact Font Format): 14 шрифтов
- **TTF** (TrueType): 12 шрифтов
- **CID** (Character Identifier): 1 шрифт

## Технические детали

### Зависимости

- `PyMuPDF` (fitz) - для работы с PDF
- `pathlib` - для работы с путями
- `collections` - для подсчета статистики
- `re` - для обработки названий шрифтов

### Обработка шрифтов

Скрипт:

1. Открывает каждый PDF файл
2. Проходит по всем страницам
3. Извлекает список шрифтов с каждой страницы
4. Очищает названия от технических префиксов
5. Собирает статистику использования
6. Создает подробный отчет

### Управление памятью

- Правильное закрытие PDF документов
- Использование `finally` блоков
- Обработка исключений

## Применение

Этот анализ полезен для:

- **Типографского анализа** - понимание используемых шрифтов
- **Проверки консистентности** - все ли страницы используют правильные шрифты
- **Планирования перевода** - какие шрифты нужны для русской версии
- **Технического аудита** - выявление проблемных файлов

## Устранение неполадок

### Ошибка "document closed"

Исправлена в текущей версии через правильное управление ресурсами.

### Большое время выполнения

Для 482 файлов анализ занимает около 2-3 минут. Это нормально.

### Проблемы с кодировкой

Все файлы создаются в UTF-8 для корректного отображения русских символов.

## Интеграция

Скрипт интегрирован в общую систему инструментов проекта:

- Использует те же зависимости что и другие скрипты
- Следует общим соглашениям по именованию
- Создает отчеты в том же стиле
