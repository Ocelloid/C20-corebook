# Создатель структуры файлов из заголовков Markdown

Этот скрипт анализирует заголовки в markdown файле и создает соответствующую файловую структуру.

## Возможности

- **Анализ заголовков**: Парсит заголовки всех уровней (# ## ### ####)
- **Создание папок**: Для заголовков с подзаголовками создает папки
- **Создание файлов**: Для заголовков без подзаголовков создает .md файлы
- **Файлы в папках**: В каждой папке создается .md файл с тем же именем
- **Безопасные имена**: Автоматически очищает имена от недопустимых символов
- **Предварительный просмотр**: Режим `--dry-run` для просмотра без создания файлов

## Использование

### Основное использование

```bash
python create_structure_from_headers.py input_file.md
```

### С указанием выходной папки

```bash
python create_structure_from_headers.py input_file.md -o "путь/к/выходной/папке"
```

### Предварительный просмотр

```bash
python create_structure_from_headers.py input_file.md --dry-run
```

### Показать дерево заголовков

```bash
python create_structure_from_headers.py input_file.md --show-tree
```

### Все опции вместе

```bash
python create_structure_from_headers.py input_file.md -o "ru/Хранилище" --dry-run --show-tree
```

## Параметры

- `input_file` - Путь к входному markdown файлу (обязательный)
- `-o, --output` - Выходная папка (по умолчанию: `ru/Хранилище`)
- `--dry-run` - Показать что будет создано без создания файлов
- `--show-tree` - Показать дерево заголовков

## Примеры

### Пример 1: Базовое использование

```bash
python create_structure_from_headers.py ru/05_chapter_one_a_world_of_darkness.md
```

Создаст структуру в папке `ru/Хранилище/`

### Пример 2: Предварительный просмотр

```bash
python create_structure_from_headers.py ru/05_chapter_one_a_world_of_darkness.md --dry-run --show-tree
```

Покажет:

- Дерево заголовков из файла
- Список файлов и папок которые будут созданы
- Не создаст никаких файлов

### Пример 3: Другая выходная папка

```bash
python create_structure_from_headers.py ru/05_chapter_one_a_world_of_darkness.md -o "структура_главы_1"
```

Создаст структуру в папке `структура_главы_1/`

## Структура результата

Для заголовков:

```markdown
# Глава первая

## Подменыши

### Два мира, одна жизнь

### Кризалис

## История

### Мифическая эпоха
```

Будет создана структура:

```
Глава первая/
├── Глава первая.md
├── Подменыши/
│   ├── Подменыши.md
│   ├── Два мира, одна жизнь.md
│   └── Кризалис.md
└── История/
    ├── История.md
    └── Мифическая эпоха.md
```

## Особенности

1. **Безопасные имена файлов**: Символы `<>:"/\\|?*` заменяются на `_`
2. **Ограничение длины**: Имена файлов ограничены 100 символами
3. **Существующие файлы**: Не перезаписывает существующие файлы
4. **Кодировка**: Все файлы создаются в UTF-8
5. **Заголовок в файле**: Каждый созданный .md файл содержит заголовок с названием
